# Code of conduct

Paperglass follows the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, be specific, assume good faith, and keep disagreements about the work. Reports of unacceptable behaviour go to the maintainer at the address on the GitHub profile and are handled privately.

One addition specific to this project: Paperglass scans documents people wrote about themselves. Contributors never add a real resume, manuscript or personal document to the repository, and report copy never calls a person a cheat or a fraud; it says what was hidden and where.
