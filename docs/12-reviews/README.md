# 12-reviews

Reviews are written when they earn their place, not on a schedule. This is a personal open-source project; the record of what exists is `README.md`, `SCOPE.md`, `THREATS.md` and `BENCHMARK.md`.

| Document | What it holds |
|----------|---------------|
| `FALSE_POSITIVE_REVIEW.md` | Every false-positive report: what was flagged, why, the fix, the fixture that now guards it |
| `REVIEW_UC<n>.md` | The review after each use case (the build loop), with the resolution of every finding |
| (as needed) `COLD_READ_<version>.md` | A cold read of the repository before a release, when one is done |

Related: `../../CONTRIBUTING.md` (add a sample), `../09-testing/FIXTURES.md` (false-positive fixtures).
