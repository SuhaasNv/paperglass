# Paperglass: Stories (ISSUES.md)

This file mirrors the Notion board ("Paperglass", Stories database) one to one: same ids, same titles, same epic, priority, week, version and status. The board is the live truth; this file is updated in the same turn as any board change so the repository is self-contained. Each story also opens a GitHub issue when it starts, so the merge can close it. Story format: `US-xxx: As a [user], I want [capability], so that [value].` Definition of Done: `DEFINITION_OF_DONE.md`. Week plan and cut order: `ROADMAP.md`.

Last synced from the board: 22 Sep 2026. Stories: 91. Statuses: Not started, In progress, Done. Priorities: MUST, SHOULD, COULD, DEFERRED. Version is the release the story ships in (use-case number equals release number).
