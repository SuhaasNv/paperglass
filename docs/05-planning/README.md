# 05-planning

Twelve weeks, one release per use case, one maintainer at 15 to 20 hours a week. Written 22 Sep 2026.

| Document | What it holds |
|----------|---------------|
| `ROADMAP.md` | Week by week, the release each week serves, load per week, the weekly close ritual, the cut order |
| `ISSUES.md` | Every story, mirrored 1:1 from the Notion board (regenerated at each board change) |
| `DEFINITION_OF_DONE.md` | Story-level, release-level and weekly-close checklists |
| `RELEASE_PLAN_V0_1_0.md` | The first release in detail: stories, order, exit criteria, what is cut first |

Start with `ROADMAP.md`. Board: Notion "Paperglass". Related: `../10-operations/BRANCHING.md`, `../10-operations/RELEASE_CHECKLIST.md`.
