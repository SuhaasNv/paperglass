# Benchmark design

## Purpose

One corpus, one harness, comparable numbers for any detector, and a public record of where each one is fooled. The benchmark is the part of Paperglass most useful to others even if the scanner were average.

## Sources (v1)

| Source | Licence | What it brings | Caveat recorded with every use |
|--------|---------|----------------|--------------------------------|
| CrackedPDFs | MIT | 29,322 synthetic PDFs, 9,774 injected, 14 templates | placement labels record requested, not actual, positions; nearly all payloads off-page bottom-left; F1 here mostly measures off-page detection |
| PhantomText generated | MIT (toolkit), attributed | 19 techniques across PDF, DOCX, HTML | generated by us with the toolkit; generator version and seed recorded |
| Semantic Integrity canaries | by request; rebuilt from the paper if no reply by week 3 | 25 canaries for font, ActualText, order and decoding gaps | rebuilt canaries are labelled rebuilt |
| PhantomLint fixtures | BSD-3 | real arXiv papers and CVs with and without hidden prompts | small |
| Paperglass Red Kit | CC BY 4.0 | seeded samples with matched controls (v2) | ours; never used for a headline number |
| Benign corpus | per source: arXiv CC BY subset, SEC EDGAR (public domain), government circulars, accessibility samples (tagged PDFs, scans with OCR layers, accessible DOCX) | at least 5,000 real documents with legitimate hidden content on purpose | downloaded by script, not redistributed where a licence forbids; count and hashes in the index |

## Hygiene (CrackedPDFs recipe, adopted)

- Hard-provenance split by base document: an injected sample and its clean control never straddle train and test.
- Confounders derived from the same base document (benign hidden content, benign small text, benign metadata).
- Metadata, file paths, ids and generator fingerprints are forbidden as features; the harness strips them.
- Label-shuffle check: with shuffled labels a detector's F1 must collapse to about 0.5; if it does not, the harness reports leakage.
- Shortcut audit: a text-only TF-IDF baseline is run; if it scores well, the split is broken.
- Unseen-generator split: one generator (PhantomText or Red Kit) held out entirely to measure generalisation.
- Held-out attack families reported separately; never the average alone.
- Versions are immutable: v1 (v0.3.0), v2 (v0.5.0), each with a Zenodo DOI; results always name the version.

## Metrics per detector

Precision, recall, F1 overall (sanity only); recall per technique and per family; data-injection recall separate from instruction-injection recall; false positives on the benign corpus split into verdict-driving (target at or below 0.1 percent) and informational (reported, no target); benign-hidden items labelled malicious (target zero); fidelity for sanitisers (benign words retained, target at least 99.9 percent); latency p50 and p95 per page on a named CPU; parser-fooled table (which extractors return each hidden run, from `paperglass fingerprint`).

## Honesty

Non-default flags stated; synthetic labelled synthetic; a number without a command does not exist; PhantomLint's phrase gate stated and, where the code allows, results with and without it; Paperglass headline numbers only on corpora Paperglass did not generate; the four research groups receive their numbers before publication.
