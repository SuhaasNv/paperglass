# Docling (v0.4.0, US-062)

Planned, two roles. As a pipeline step: scans the source before conversion and attaches the shared metadata to the `DoclingDocument`. As a View A extractor: `paperglass fingerprint` and `--extractor docling` use Docling's text so a Docling user sees whether their own parser is fooled. Extra: `paperglass[docling]`. A pull request offering the step upstream is part of the story (docling-parse issue 134 has had no maintainer reply, so a pull request is the route).
