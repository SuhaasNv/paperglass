# 04-report-design

The web app screens, the HTML report, the CLI contract and the accessibility rules. Written 22 Sep 2026, before code; the record for anything a reviewer sees. Layout, verdict set, severity classes, thresholds, profiles and the plain-language sentences do not change without the owner's approval.

| Document | What it holds |
|----------|---------------|
| `DESIGN_DIRECTION.md` | The brief for the design pass: what it is, tone, what to avoid, a paper-and-ink palette proposal, type, layout notes per screen |
| `REPORT_DESIGN.md` | The results screen and the downloadable one-file HTML report: layout, the diff view, overlays, copy rules, profiles |
| `CLI_DESIGN.md` | Commands, flags, exit codes, output modes |
| `ACCESSIBILITY.md` | Label plus shape, contrast, keyboard, print, no colour-only meaning |

Start with `DESIGN_DIRECTION.md`, then `REPORT_DESIGN.md`. Related: `../02-requirements/USE_CASES.md` UC2, `../03-architecture/FINDING_SCHEMA.md`.
